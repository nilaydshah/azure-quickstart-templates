💡 Key Insights

NIC Throttling Eliminated
By using inline networkInterfaceConfigurations, CRP creates NICs internally. This bypasses ARM rate limits entirely — zero 429s for NIC operations.
Throttle Redistribution
With NIC bottleneck removed, the burst of 5,000 VM + 15,000 Disk PUTs hits ARM simultaneously, causing higher VM/Disk throttling. But total time still 2.5× faster because there's no sequential NIC→VM dependency.
CRP Internal NIC Creation
CRP's NrpCallback.AllocateTenantNetworkResources handles NIC creation internally with avg 24ms latency (vs ARM NIC PUTs that took seconds and got throttled).
