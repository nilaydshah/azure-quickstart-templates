11. Key Findings & Recommendations

🔍 Findings

  1. Cold CRP pool = 0% hit rate. All VMs created from scratch. Pool needs 2+ hours post-cleanup to refill.
  2. SA pool severely degraded. 29% of SA allocations took >10s, with 14.5% >60s (avg 121s). This is the #1 latency contributor.
  3. Zone 1 is unreliable for DDSv5. Consistent OverconstrainedZonalAllocationRequest across Run 9 and Run 10.
  4. DiskRP disk creation is extremely fast. P99=11ms for 18,482 disks — not a bottleneck.
  5. DirectDriveGateway performance excellent. P50=26ms, P90=64ms for PatchDisk operations.
  6. SRP confirmed bypassed for PremiumV2_LRS — no DNS overhead.

💡 Recommendations

  1. Use Zone 3 only to avoid Zone 1 allocation failures. Could deploy all 4,000 VMs in Zone 3.
  2. Allow pool recovery time. Wait 2+ hours after cleanup before next run for CRP/DiskRP pool refill.
  3. Pre-warm SA pool by deploying a small batch (100 VMs) 30 minutes before main burst to prime the pool.
  4. Increase SA pool quota (if configurable) — 1,679 severe misses indicate pool capacity is insufficient for 12K disk burst.
  5. Monitor batch-04 anomaly. This batch took 21:36 vs 7-8 min for others — investigate ARM retry/backoff behavior.
  6. Target 5K VMs by waiting for quota availability (need 10K DDSv5 vCPUs free).
