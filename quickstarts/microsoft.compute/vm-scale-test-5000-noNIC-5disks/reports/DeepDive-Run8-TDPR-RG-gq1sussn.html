6. Key Findings

✅ What Worked

NoNIC still effective: Zero NIC 429s confirmed again. CRP's NrpCallback handles inline NICs with zero throttling.
ARM PUT burst faster: All PUTs completed in 4 min (vs 6 min in Run 7) — despite 50% more disk PUTs.
DiskRP internal performance unchanged: 2ms avg PUT callback, 100% success for created disks.
CRP VM PUT improved: P50 dropped from 794ms → 663ms (-16%).

❌ Issues

PremiumV2DiskCount quota (20,000): With 3 data disks × 5K VMs = 15K needed, plus transient/retry allocations, the quota was exhausted. 6 VMs failed, many VMs got fewer than 3 data disks.
Disk ARM throttling 2.8×: 53K disk 429s vs 19K — adding 1 more data disk per VM significantly increases ARM pressure on disk PUTs.
DiskRP AllocateDisks 61.4% success: Down from 100% — quota rejections propagated as allocation failures.
Recommendation: For future runs with 3+ data disks, request a PremiumV2DiskCount quota increase to at least 25,000 (15K data + 5K OS + buffer for retries). Alternatively, use 2 data disks (Run 7 config) which fits comfortably within the 20K quota.
